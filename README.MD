# Website SD Negeri 032 Mamugo

Ini adalah website resmi SD Negeri 032 Mamugo yang dibuat untuk menampilkan informasi penting kepada siswa, guru, dan orang tua.

## Fitur Utama

- **Halaman Beranda**: Menampilkan jam operasional, kontak sekolah, dan sambutan kepala sekolah.
- **Daftar Siswa per Kelas**: Menampilkan nama dan tempat tinggal siswa, per kelas (1–6).
- **Jadwal Pelajaran**: Jadwal khusus per kelas, bisa diatur dari panel admin.
- **Panel Admin**:
  - Login admin
  - Tambah siswa per kelas
  - Tambah jadwal pelajaran
  - Ganti latar belakang halaman dan per kelas (via URL gambar)
  - Tambah pengumuman dan agenda mingguan
  - Upload galeri foto kegiatan beserta keterangan
  - Ubah sambutan kepala sekolah

## Cara Menggunakan

1. Buka file `index.html` di browser untuk melihat tampilan web.
2. Gunakan panel admin untuk menambahkan konten. Data disimpan di localStorage (belum terhubung ke database online).
3. Upload gambar untuk latar belakang dan galeri menggunakan URL dari layanan seperti [imgur.com](https://imgur.com).

## Teknologi

- HTML
- CSS
- JavaScript (tanpa backend)
- Disimpan di localStorage (sementara)

## Lisensi

Website ini dibuat untuk keperluan pendidikan dan penggunaan internal SD Negeri 032 Mamugo.
